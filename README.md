# Quietwire updates

Public version manifest and changelog for **Quietwire**, the private file dock
for Tailscale networks by ACAS Tools.

Quietwire reads `update-manifest.json` from this repository's `main` branch when —
and only when — a user clicks **check for updates** in the dock footer. The
request carries no account, device, file, or usage information, and Quietwire
never downloads or runs an installer itself; it only reports whether a newer
version exists and links the release download page.
